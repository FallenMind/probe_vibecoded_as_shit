# «Пионер» — Протокол прорыва

Прототип IDLE-игры о прорыве механизированного человека сквозь каменную карту. Он почти ничего не помнит, но чувствует, что прежде был важен и должен вернуть многое из утраченного.

**Стек:** TypeScript + Phaser 4 + Vite.

## Идея

Персонаж автоматически идёт к ближайшему камню, добывает породу и продвигается
сквозь последовательность квадратных блоков. Спереди постепенно приближается
граница опасной зоны. Цель — очистить все 50 блоков и добраться до выхода.

## Геймплей

В начале добывайте камень кулаками. Сборщик включает автоматическую добычу и открывает оружие. Повторяемые улучшения открываются после зачистки половины карты. Каждая карта имеет размер 25×25; граница начинает движение после трёх учебных карт.

- Кремневая кирка бьёт в секторе 210°, а урон уменьшается с расстоянием. Игломёт запускает снаряды по задним камням и учитывает попадания в пути. Его автономный режим доступен с 20-го квадрата за 25 кристаллов и стреляет с четвертью обычной скорострельности, когда выбрано другое дальнее оружие. Излучатель плавно перемещает луч и наносит урон по области, затухающий к её краям.
- Для особых улучшений нужны кристаллы. Ближнее и дальнее оружие переключается независимо; у каждого есть собственные улучшения.
- Реагент накапливается отдельно. Собранные заряды автоматически усиливают
  добычу элементальной руды.
- Артефакт «Эхо пустоты» открывается с 25-го квадрата и наносит небольшой урон камням в текущем и соседних квадратах; его сила возрастает, когда вокруг камня остаётся мало соседей.
- При встрече с границей карта и обычные ресурсы сбрасываются. Улучшения,
  оружие и редкие ресурсы сохраняются. За полное прохождение выдаётся очко
  прорывателя; после этого можно расширять блоки для следующих попыток.
- Клавиши **P** и **Escape** ставят игру на паузу и снимают её.

Игровой баланс находится в `src/game/breachConfig.ts`. Текущий цикл до Break
Infinity расположен в `src/game/breach.ts`, движение и выбор оружия — в
`movement.ts` и `weapons.ts`. Цикл после Break Infinity пока не реализован.

## Запуск

```bash
npm install
npm run dev      # http://localhost:5173/
```

Production-сборка:

```bash
npm run build    # dist/
npm run preview
npm test         # проверки игрового цикла
```

## Публикация на GitHub Pages

В репозитории есть workflow [`.github/workflows/deploy.yml`](.github/workflows/deploy.yml).
Чтобы включить публикацию:

1. **Settings → Pages**;
2. **Build and deployment → Source**: выбери **GitHub Actions**;
3. На вкладке **Actions** дождись успешного `Deploy to GitHub Pages`;
4. Ссылка на игру появится в deployment и в разделе Pages.

## Сохранение

Автосохранение каждые 5 секунд в `localStorage`. При возвращении рассчитывается
до 8 часов оффлайн-прогресса. Сохранение прототипа использует отдельный ключ;
сохранение прежней версии игры не перезаписывается.
