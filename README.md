# «Пионер» — Протокол прорыва

Прототип IDLE-игры о прорыве механизированного человека сквозь каменную карту. Он почти ничего не помнит, но чувствует, что прежде был важен и должен вернуть многое из утраченного.

**Стек:** TypeScript + Phaser 4 + Vite.

## Идея

Персонаж автоматически идёт к ближайшему камню, добывает породу и продвигается
сквозь последовательность квадратных блоков. Спереди постепенно приближается
граница опасной зоны. Цель — очистить все 50 блоков и добраться до выхода.

## Геймплей

В начале добывайте камень кулаками. Сборщик включает автоматическую добычу и открывает оружие. Повторяемые улучшения открываются после зачистки 30% карты. Каждая карта имеет размер 25×25; граница начинает движение после трёх учебных карт.

Расположение твёрдой и элементальной породы определяется шумом Перлина по общей прямоугольной карте, поэтому залежи могут пересекать границы квадратов. Здоровье породы растёт быстрее до 3-го квадрата, затем медленнее. После 5-го, 15-го и 35-го квадратов каждый сломанный блок даёт дополнительно по 1 руде.

- Кремневая кирка бьёт в секторе 210°, а урон уменьшается с расстоянием. Игломёт запускает снаряды по задним камням и учитывает попадания в пути. Его автономный режим доступен с 20-го квадрата за 25 кристаллов и стреляет с четвертью обычной скорострельности, когда выбрано другое дальнее оружие. Излучатель плавно перемещает луч и наносит урон по области, затухающий к её краям; скорость перемещения луча можно улучшать отдельно.
- Для особых улучшений нужны кристаллы. Ближнее и дальнее оружие переключается независимо; у каждого есть собственные улучшения.
- Кирка открывается на третьем квадрате за 1000 руды, копьё — на 25-м за 30000 руды и 5 кристаллов. Комбо кулаков покупается отдельно; комбо кирки и копья открываются после завершения Challenge 1.
- Нажатия заполняют скрытый буфер: он ускоряет атаки и при заполнении свыше 10% ускоряет движение максимум на 40%. Нажатие вблизи цели может потратить единицу буфера, чтобы сбросить оставшееся время до удара. Если удар готов, буфер не тратится.
- Частые клики создают перегрев: при 4 кликах в секунду примерно минуту рамка карты начинает слегка дрожать, меняет тон и показывает частицы.
- Артефакт «Эхо пустоты» открывается с 25-го квадрата и наносит небольшой урон камням в текущем и соседних квадратах; его сила возрастает, когда вокруг камня остаётся мало соседей.
- При встрече с границей карта и обычные ресурсы сбрасываются. Улучшения,
  оружие и редкие ресурсы сохраняются. За полное прохождение выдаётся очко
  прорывателя; после этого можно расширять блоки для следующих попыток.
- Клавиши **P** и **Escape** ставят игру на паузу и снимают её.

Во вкладке «Алхимия» Земля открывается на 20-м квадрате, Вода — на 30-м. Воздух открывается после тестовой арены Challenge 1 (квадрат 35), Огонь — после Challenge 4. Арена Challenge 1 — отдельная карта 2×2 с камнями вчетверо прочнее, она не расходует ресурсы основной карты и выдаёт 10 Воздуха. Обычный камень превращается в Землю, а Земля и элементальный камень — в Воду; Воду можно обменять на кристаллы.

За тик Земля преобразует 10% запаса камня 1:1, а Вода — до 10% запаса Земли, расходуя 2 элементальных камня на единицу Воды. Минимум за тик — 1 единица; нехватка ингредиентов и предел запаса ограничивают производство. Скорость каждого рецепта можно один раз удвоить за соответствующий элемент. Кристаллизация стоит 50 Воды.

Обычная порода даёт 1 камень, твёрдая — 3, элементальная — 2 камня и 1 элементальный камень. Камень для алхимии учитывается отдельно от руды. Усиление кулаков и кирки снимает сопротивление элементальной породы и расходует Землю на прямые удары; удары по области Землю не усиливают. За одну атаку, задевшую элементальную породу, копьё расходует 1 Воздух и игнорирует её сопротивление. При сбросе попытки алхимические материалы обнуляются, но купленные улучшения и переключатели сохраняются.

Рецепты и набор улучшений алхимии находятся в `src/game/alchemy.ts`; стоимость, лимит, необходимые улучшения, квадрат и испытание задаются данными. Текущие скорости и обмен Воды на кристаллы — настройки прототипа.

Игровой баланс находится в `src/game/breachConfig.ts`. Текущий цикл до Break
Infinity расположен в `src/game/breach.ts`, движение и выбор оружия — в
`movement.ts` и `weapons.ts`. Цикл после Break Infinity пока не реализован.

## Запуск

```bash
npm install
npm run dev      # http://localhost:5173/
```

Production-сборка:

```bash
npm run build    # dist/
npm run preview
npm test         # проверки игрового цикла
```

## Публикация на GitHub Pages

В репозитории есть workflow [`.github/workflows/deploy.yml`](.github/workflows/deploy.yml).
Чтобы включить публикацию:

1. **Settings → Pages**;
2. **Build and deployment → Source**: выбери **GitHub Actions**;
3. На вкладке **Actions** дождись успешного `Deploy to GitHub Pages`;
4. Ссылка на игру появится в deployment и в разделе Pages.

## Сохранение

Автосохранение каждые 5 секунд в `localStorage`. При возвращении рассчитывается
до 8 часов оффлайн-прогресса. Сохранение прототипа использует отдельный ключ;
сохранение прежней версии игры не перезаписывается.

Кнопка «Сбросить прогресс» в верхней панели после подтверждения удаляет сохранение этого прототипа и начинает новую игру. Сохранение прежней версии игры не удаляется.
