# «Пионер» — Протокол прорыва

Браузерная idle-игра на TypeScript и Canvas. Механизированный персонаж добывает камень, улучшает оружие и проходит последовательность карт.

## Игра

- Персонаж автоматически добывает камни на карте 25×25 и движется дальше после её очистки.
- Ближнее оружие управляет движением, дальнее атакует автономно. Комбо и сплеш формируются теми же планами атак.
- Клики наполняют скрытый буфер, который ускоряет атаки и передвижение. **P** или **Escape** ставят игру на паузу.
- Прогресс включает боссовые карты, испытания, алхимию, артефакты и постоянные улучшения.

## Структура

- `src/main.ts` — запуск игры и привязка DOM-событий.
- [`src/game/`](src/game/README.md) — единственная реализация игры: состояние, игровой цикл, оружие, бой, мир, алхимия, улучшения, испытания и визуальные эффекты.
- `src/app.css` и `src/framework.css` — стили приложения.
- [`docs/framework-wiki.md`](docs/framework-wiki.md) — схема модулей, правила их взаимодействия и известные ограничения.
- [`AGENTS.md`](AGENTS.md) — рабочие правила проекта; [`CHANGELOG.md`](CHANGELOG.md) — журнал изменений.

Старая Phaser-реализация и её переходные адаптеры удалены. Новая игра хранит состояние в `GameState` через `StateBus`; второй независимой игровой реализации больше нет.

## Запуск

```bash
npm install
npm run dev
npm run typecheck
npm run build
npm test
```

Сборка размещается в `dist/`; локальный production-предпросмотр запускается `npm run preview`.

## Сохранения

Игра использует ключ `pioneer-framework-v1`. Старое сохранение `pioneer-breach-v1` автоматически не переносится. Оффлайн-прогресс пока не реализован.
