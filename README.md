# 🛰️ Зонд «Пионер» — Система Дальняя

IDLE-игра про автономный исследовательский зонд в далёкой звёздной системе.

**Стек:** TypeScript + Phaser 4 + Vite.

## Идея

Игрок управляет автономным исследовательским зондом, который раскрывает тайны
далёкой системы. Прогрессу мешают три вещи:

- **медленное накопление данных** — данные капают сами по себе, но медленно;
- **износ модулей** — корпус постепенно разрушается, нужен ремонт за руду;
- **ограниченные ресурсы** — энергия тратится на фазы цикла и клики, при нуле
  зонд встаёт на подзарядку.

## Геймплей

Интерфейс разделён на две части: **меню слева**, **корабль справа** (Phaser-сцена).

Основной idle-цикл автоматический:

1. **🔭 Исследование** — зонд летит и накапливает научные данные;
2. **☄️ Астероид** — на радаре появляется астероид;
3. **⛏️ Добыча** — лазер дробит астероид, игрок получает руду;
4. **🚀 Перелёт** — марш к следующему региону;
5. **🌩️ Солнечная буря** (шанс ~35%) — нужно кликать «Отвести щит» (20⚡),
   иначе буря повредит корпус.

Клики ускоряют текущую фазу: при исследовании дают данные, при добыче — урон
по астероиду. Кнопка «⚡ Ускорить» (10⚡) мгновенно завершает фазу.

### Модернизация зонда

| Улучшение | Эффект |
|---|---|
| 🔋 Энергоячейка | +макс. энергия, +регенерация |
| ⛏️ Добывающий лазер | +урон по астероидам, +руда |
| 📡 Антенна | +данные/сек, короче исследование |
| 🛡️ Бронеплиты | +корпус, −урон от среды |
| 🧲 Сканер | богаче астероиды, короче перелёты |

### Тайны системы

Каждые `250 · 1.9ⁿ` данных зонд разгадывает тайну: случайный бонус (руда,
ремонт, энергия или поток данных) и постоянные **+10% к скорости сбора**.

### Сектора

По мере удаления от базы открываются новые сектора с уникальными названиями —
они ускоряют добычу данных и руды.

## Запуск

```bash
npm install
npm run dev      # http://localhost:5173/
```

Production-сборка:

```bash
npm run build    # dist/
npm run preview
```

## Публикация на GitHub Pages

В репозитории есть workflow [`.github/workflows/deploy.yml`](.github/workflows/deploy.yml).
Чтобы включить публикацию:

1. **Settings → Pages**;
2. **Build and deployment → Source**: выбери **GitHub Actions**;
3. На вкладке **Actions** дождись успешного `Deploy to GitHub Pages`;
4. Ссылка на игру появится в deployment и в разделе Pages.

## Сохранение

Автосохранение каждые 5 секунд в `localStorage`. При возвращении после перерыва
зонд обрабатывает оффлайн-прогресс (данные и руда с пониженной эффективностью).
