# «Пионер» — Протокол прорыва

Браузерный прототип idle-игры: механизированный персонаж добывает камень и прорывается через последовательность карт. Проект использует TypeScript, Phaser 4 и Vite.

## Игра

Персонаж ищет ближайшую породу внутри текущего квадрата. После очистки карты он продвигается к её верхней границе и переходит дальше. Основной забег состоит из 50 квадратов; после обучения навстречу начинает двигаться граница.

- Игрок начинает с кулаками, открывает автоматическую добычу, ближнее и автономное дальнее вооружение. У оружия есть собственные улучшения и комбо.
- Клики пополняют скрытый буфер, который ускоряет атаки и движение. Пауза включается и выключается клавишами **P** или **Escape**.
- На пути встречаются боссовые квадраты, испытания и артефакт. После полного прохождения выдаётся очко прорыва, доступное для постоянных улучшений.
- Земля и Вода открываются после 20-го квадрата; дальнейшие стихии связаны с испытаниями. Ресурсы алхимии используются для производства и усилений, а 100 Воды можно обменять на кристалл.

Точный баланс и условия открытия могут меняться. Текущие значения находятся в `src/game/breachConfig.ts`, `src/game/alchemy.ts` и `src/game/challengeConfig.ts`.

## Устройство проекта

- `src/breachMain.ts` и `src/breach.css` — интерфейс действующей игры; `src/game/BreachScene.ts` — её Phaser-сцена.
- `src/game/breach.ts` — правила забега и состояние, `movement.ts` и `weapons.ts` — движение и оружие.
- [`src/framework-draft/`](src/framework-draft/README.md) — отдельный черновик будущей архитектуры. Он ещё не подключён к игре; перенос текущих механик и сохранений не выполнен.
- [`AGENTS.md`](AGENTS.md) содержит правила работы над проектом, [`CHANGELOG.md`](CHANGELOG.md) — журнал изменений.

## Запуск и проверки

```bash
npm install
npm run dev         # адрес покажет Vite
npm run typecheck
npm run build
npm test            # проверки действующей игры
node --test src/framework-draft/framework.test.mjs  # проверки каркаса
```

Production-сборка находится в `dist/`; для локального просмотра используйте `npm run preview`.

Набор `tests/breach.test.mjs` пока требует сверки с текущими механиками: в нём остались ожидания старых правил, и часть тестов не проходит. Проверки каркаса запускаются отдельно указанной выше командой.

## Сохранение

Игра автоматически сохраняется в `localStorage`. При возвращении учитывается до восьми часов оффлайн-прогресса. Кнопка «Сбросить прогресс» после подтверждения удаляет сохранение текущего прототипа; старое сохранение зонда не удаляется.

## Публикация на GitHub Pages

В репозитории есть workflow [`.github/workflows/deploy.yml`](.github/workflows/deploy.yml). Для публикации выберите **Settings → Pages → Source: GitHub Actions**, затем дождитесь выполнения workflow на вкладке **Actions**.
