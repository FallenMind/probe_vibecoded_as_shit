# «Пионер» — Протокол прорыва

Браузерный прототип idle-игры: механизированный персонаж добывает камень и прорывается через последовательность карт. Действующая версия использует TypeScript, Canvas и Vite.

## Игра

Персонаж ищет ближайшую породу внутри текущего квадрата. После очистки карты он продвигается к её верхней границе и переходит дальше. Основной забег состоит из 50 квадратов; после обучения навстречу начинает двигаться граница.

- Автоматическая добыча начинается с кулаками; игрок открывает ближнее и автономное дальнее вооружение, их улучшения и комбо.
- Клики пополняют скрытый буфер, который ускоряет атаки и движение. Пауза включается и выключается клавишами **P** или **Escape**.
- На пути встречаются боссовые квадраты, испытания и артефакт. После полного прохождения выдаётся очко прорыва, доступное для постоянных улучшений.
- Земля и Вода открываются после 20-го квадрата; дальнейшие стихии связаны с испытаниями. Ресурсы алхимии используются для производства и усилений, а 100 Воды можно обменять на кристалл.

Баланс и правила новой версии упрощены и ещё требуют настройки. Параметры находятся в `src/framework/config/defaults.ts`, а правила конкретного режима — в `src/framework/runtime/`.

## Устройство проекта

- `src/frameworkMain.ts`, `src/breach.css`, `src/framework.css` и `runtime/screen.ts` — действующий интерфейс; `animation/canvasVisuals.ts` — отрисовка карты и эффектов.
- [`src/framework/`](src/framework/README.md) — действующий каркас; `runtime/game.ts` собирает режим и управляет состоянием, `runtime/delivery.ts` доставляет атаки. [Мини-вики](docs/framework-wiki.md) описывает границы и ограничения.
- `src/game/`, `src/breachMain.ts` и переходные адаптеры сохранены как предыдущая реализация и не используются активной точкой входа.
- [`AGENTS.md`](AGENTS.md) содержит правила работы над проектом, [`CHANGELOG.md`](CHANGELOG.md) — журнал изменений.

## Запуск и проверки

```bash
npm install
npm run dev         # адрес покажет Vite
npm run typecheck
npm run build
npm test                # каркас и действующий режим
npm run test:legacy     # отдельный набор предыдущей игры
```

Production-сборка находится в `dist/`; для локального просмотра используйте `npm run preview`.

Набор `tests/breach.test.mjs` пока требует сверки с текущими механиками: в нём остались ожидания старых правил, и часть тестов не проходит. Проверки каркаса запускаются отдельно указанной выше командой.

## Сохранение

Игра автоматически сохраняет `GameState` в `localStorage` под ключом `pioneer-framework-v1`. Прежний ключ `pioneer-breach-v1` не читается и не удаляется, поэтому новый режим начинается с начала. Оффлайн-прогресс в новом режиме пока не реализован. Кнопка «Сбросить прогресс» после подтверждения удаляет только новое сохранение.
